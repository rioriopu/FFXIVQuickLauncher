# ランタイムの確認と修復

設定の「ゲーム内機能」タブにある「ランタイムの確認・修復」から開きます。
起動時の警告に表示された系列（.NET 6・8・9）を選ぶと、Windows x64 の .NET Runtime と Desktop Runtime の導入状況を表示します。
別系列のランタイムが入っていても、選択した系列の代わりにはなりません。

「修復」を押したときだけ、Microsoft 公式の配布情報から同じ系列の最新パッチを調べ、Desktop Runtime のインストーラーを取得します。
Desktop Runtime には .NET Runtime も含まれます。
公開された SHA-512 と一致した場合だけインストーラーを開きます。
その画面の案内に従って導入または修復してください。自動的な無人インストールは行いません。
終了後は導入状況を再確認します。再起動が必要な場合はインストーラーの案内に従ってください。
.NET 6 は互換用であり、Microsoft のサポートは終了しています。

確認・取得・検証・終了の履歴は画面の直近20件と通常ログの `[RuntimeRepair]` に残ります。
取得中に確認画面を閉じると、取得を中止します。
取得済みのインストーラーは `%LOCALAPPDATA%\XIVLauncher\runtime-repair` に保存し、再利用時にも検証します。

Dalamud 専用のランタイムは、各データフォルダの `runtime` にあります。
こちらは配布情報に指定された版をゲーム起動前に自動確認します。
7.0.33 以降は取得・展開・検証を一時領域で完了してから追加し、旧版のフォルダは保持します。
同じ保存先への更新は順番に処理します。

この画面の確認対象は Windows 側です。個別アプリが専用の保存先を使っている場合は、そのアプリ側の修復が必要なことがあります。
警告を出すアプリの所在が不明な場合、ランタイム不足とゲームのクラッシュが同じ原因とは限りません。
